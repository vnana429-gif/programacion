Evaluación .NET Framework y Windows Forms (C#)

Guía de estudio oficial por Temas (1 a 4) enfocada en entorno .NET / C# / WinForms

P1 1. ¿En qué se diferencia la forma de desarrollo planteada en .NET respecto de la forma de desarrollo Imperativa? ¿Por qué?

La diferencia principal es que el desarrollo imperativo exige que se programe paso a paso cómo realizar cada tarea de forma manual, a diferencia de .NET que es un modelo administrado donde el desarrollador especifica sus problemas para que sean resueltos. Esta diferencia es por el motor CLR que actúa como capa intermedia que gestiona la ejecución del programa. En cambio el .NET ofrece agilidad, seguridad y estabilidad en contraparte de ese enfoque imperativo tradicional.

P5 5. ¿Qué es un módulo?

En el contexto de .NET y C#, la funcionalidad equivalente a un módulo se implementa mediante una clase estática declarada como static class. Es una estructura de código que permite agrupar métodos, funciones y variables de acceso global dentro del proyecto sin necesidad de instanciar un objeto con el operador new. Todos sus miembros deben ser estáticos (static) y se accede a ellos directamente mediante el nombre de la clase desde cualquier Form de la aplicación. Su función principal es organizar rutinas de utilidad general, variables globales o contener el punto de entrada Program.Main().

P9 9. ¿Puedo agregar un método a un control? ¿Cómo?

Sí, en C# dentro de .NET Framework es totalmente posible agregar un método a un control existente utilizando Métodos de Extensión. Para lograrlo se define un método estático dentro de una static class y se utiliza la palabra clave this antes del primer parámetro, especificando el tipo de control a extender (por ejemplo, public static void MiMetodo(this TextBox txt)). De esta manera, el nuevo método queda inyectado directamente en la clase del control y se puede invocar desde cualquier instancia en WinForms como si fuera una función nativa de la clase.

P13 13. ¿Cuáles son las propiedades que me indican la posición de un control en un formulario?

En Windows Forms con C#, la posición de un control dentro de la superficie del formulario se determina mediante sus propiedades numéricas Top y Left, o a través de la propiedad combinada Location de tipo System.Drawing.Point. La propiedad Left representa la distancia en píxeles desde el borde izquierdo del formulario contenedor, mientras que Top marca la distancia desde el borde superior. Ambas coordenadas fijan la esquina superior izquierda del control, permitiendo moverlo y ubicarlo de forma precisa dentro de la interfaz.

P17 17. ¿Con qué propiedad indico que se habilite o se deshabilite un control?

En el Framework de .NET con C#, la propiedad que determina si un control de WinForms está habilitado para interactuar con el usuario es la propiedad Enabled, la cual acepta un valor booleano (true o false). Cuando se establece en true, el control responde a eventos de mouse y teclado como clics o tipeo de texto, mientras que al ponerla en false el control se atenúa visualmente y bloquea cualquier acción. Esta propiedad es esencial en C# para manejar la lógica de la interfaz según las validaciones del sistema.

P21 21. ¿Cómo aumento el tamaño de un vector conservando su contenido?

En C# dentro de .NET Framework, para aumentar el tamaño de un vector o arreglo unidimensional conservando los elementos ya cargados se utiliza el método estático Array.Resize(ref miVector, nuevoTamaño). Al pasar el arreglo por referencia con la palabra clave ref, el entorno de .NET asigna un nuevo bloque de memoria con el tamaño deseado y copia automáticamente todos los elementos existentes al nuevo arreglo. De esta manera el vector expande su capacidad sin perder la información cargada previamente en sus posiciones anteriores.

P37 37. ¿Cuándo una Lista está vacía?

En la implementación de listas enlazadas dinámicas en C#, una lista se considera vacía cuando la variable de referencia u objeto que señala al primer nodo es igual a null (Primero == null). Esto significa que la variable de clase no apunta a ninguna instancia cargada en la memoria Heap administrada por el CLR. Al evaluar esta condición condicional, el sistema en C# confirma que la lista no contiene nodos almacenados para buscar, recorrer o eliminar dentro de su estructura.

P41 41. ¿Cuándo una Cola está llena?

En .NET Framework utilizando C#, una cola se encuentra llena cuando está basada en un arreglo de tamaño fijo y el número de elementos o el índice de Ultimo alcanza la capacidad máxima establecida. Por el contrario, si la cola está implementada con nodos dinámicos mediante referencias entre objetos, solo se considera llena cuando la memoria Heap administrada por el CLR se agota por completo al intentar usar new. Por lo tanto, la condición de límite depende strictly de si la reserva de memoria es fija o dinámica.

P2 2. ¿Qué es un Framework?

Un framework es un entorno de trabajo estructurado que provee herramientas, bibliotecas reutilizables y reglas de diseño para desarrollar software de forma eficiente. Su objetivo es resolver la arquitectura básica y las tareas repetitivas del proyecto para que el programador se enfoque en la lógica del negocio. Opera bajo inversión de control, lo que significa que el framework administra el flujo del programa e invoca el código escrito según sea necesario.

P6 6. ¿Qué es un evento?

En Windows Forms con C#, un evento es una notificación que envía un control u objeto cuando se produce una interacción sobre él, como un clic de mouse (Click) o un cambio en el texto (TextChanged). Se basa en el patrón emisor-receptor mediante delegados (event handlers), permitiendo asociar un método controlador mediante el operador +=. Cuando ocurre la acción, el CLR de .NET ejecuta automáticamente el método vinculado para responder a la interacción del usuario en la interfaz gráfica.

P10 10. En un textbox, ¿en qué evento y con qué código obligo a que solo ingrese caracteres alfabéticos?

En un TextBox de WinForms en C# se utiliza el evento KeyPress evaluando la propiedad KeyChar de los argumentos e (KeyPressEventArgs). El código utiliza el método char.IsLetter(e.KeyChar) para verificar si la tecla presionada es alfabética, permitiendo también teclas de control como char.IsControl(e.KeyChar) para el borrado. Si la tecla no cumple con estas condiciones, se asigna e.Handled = true, cancelando la propagación del evento e impidiendo que el carácter no permitido aparezca en el TextBox.

P14 14. ¿La propiedad Backcolor es común a todos los controles?. ¿Qué otras propiedades recuerda que sean comunes?

En Windows Forms con C#, la propiedad BackColor es común a casi todos los controles visuales, heredada directamente de la clase base System.Windows.Forms.Control para fijar el color de fondo. Otras propiedades comunes a todos los controles de WinForms son Name para su identificación en código, ForeColor para el color del texto, Font para la tipografía, Visible para mostrarlo u ocultarlo, Enabled para permitir o bloquear la interacción, y Location junto con Size para administrar su posición y tamaño.

P18 18. ¿Qué puede decir respecto del control de flujo en el código? ¿Qué instrucciones conoce?

En el lenguaje C# dentro de .NET Framework, el control de flujo abarca la estructura sintáctica que determina el orden de ejecución de las instrucciones según condiciones lógicas o ciclos repetitivos. Permite alterar la ejecución secuencial línea a línea para tomar decisiones o iterar sobre bloques de código. Las instrucciones condicionales principales en C# son if...else y switch, mientras que para las estructuras repetitivas se utilizan los bucles for, foreach, while y do...while.

P22 22. ¿Cómo reduzco el tamaño de un vector?

En C# dentro de .NET Framework, para reducir el tamaño de un vector o arreglo unidimensional se utiliza el método estático Array.Resize(ref miVector, nuevoTamaño) pasando una dimensión menor a la actual. Al invocar esta función con la palabra clave ref, el entorno de .NET asigna un nuevo bloque de memoria acortado y copia los elementos que caben en la nueva capacidad. Los elementos que superan el nuevo límite superior del arreglo se eliminan automáticamente de la memoria administrada.

P38 38. ¿Cuándo una Cola está vacía?

P42 42. ¿Cuándo una Pila está llena?

En C#, una Pila está llena cuando está implementada sobre un arreglo estático de tamaño fijo y el índice o puntero de tope alcanza el límite de capacidad máxima definido. Si la Pila está construida mediante nodos dinámicos enlazados con referencias de objetos, solo se considera llena cuando la memoria Heap administrada por el CLR se agota al intentar instanciar un nuevo nodo con new. De este modo, la condición de tope máximo depende de si la estructura es de capacidad fija o dinámica.

P46 46. Complete Algoritmo de Búsqueda / Modificación en Lista

En cada paso verifica si el dato del nodo coincide con el valor buscado, cambiando una variable booleana existe a true al encontrarlo. Una vez localizado el nodo en la lista, el algoritmo permite modificar directamente su propiedad de datos antes de dar por finalizada la iteración.

P50 50. Diseñe algoritmo para quitar un nodo a una Pila. Use sus propias variables

En C#, para quitar un nodo de una Pila se verifica primero que la estructura no esté vacía con if (tope != null). Luego se guarda el dato del nodo en una variable auxiliar para retornarla y se actualiza la referencia tope = tope.Siguiente para señalar al nodo inferior. Al quedar el nodo desvinculado sin referencias que lo apunten, el recolector de basura (Garbage Collector) de .NET se encarga de liberar la memoria Heap sobrante y se decrementa el contador de elementos.

P3 3. ¿Qué es un Formulario?

En Windows Forms de .NET con C#, un formulario es una clase que hereda de System.Windows.Forms.Form (public class MiForm : Form) y representa la ventana gráfica de la aplicación. Actúa como el contenedor principal donde se alojan los controles interactivos como botones, cuadros de texto y etiquetas. Además constituye la unidad fundamental donde se encapsula la lógica de presentación de la interfaz y la respuesta a eventos visuales del usuario en .NET.

P7 7. ¿Qué es un método?. ¿Qué tipos conoce? ¿Qué devuelve cada uno?

En C# dentro de .NET Framework, un método es un bloque de código reutilizable estructurado dentro de una clase que ejecuta una tarea al ser invocado. Se dividen en dos tipos según su tipo de retorno: métodos que no devuelven valor declarados con el tipo void (equivalentes a procedimientos), y métodos que retornan un valor especificando el tipo de dato devuelto (int, string, bool, etc.). Los métodos con retorno emplean la instrucción return para entregar el resultado obtenido.

P19 19. ¿Qué ámbito puede tener una variable?

P40 40. ¿Cuándo una Lista está llena?

En C# dentro de .NET Framework, una lista enlazada dinámica basada en clases de nodos solo se considera llena cuando la memoria Heap del CLR se agota por completo al intentar asignar espacio con new. Si la lista estuviera implementada sobre una estructura fija de arreglo, estará llena cuando alcance el límite superior del índice. En la práctica habitual con referencias dinámicas de objetos en C# no existe un límite de capacidad predefinido.

P44 44. ¿Qué es una TDA?

Un TDA o Tipo de Dato Abstracto en C# es un modelo que define una estructura de datos abstracta junto con el conjunto de operaciones o métodos públicos permitidos sobre ella, independientemente de cómo esté codificada internamente. Representa una especificación lógica que oculta la complejidad del almacenamiento en memoria Heap ofreciendo una interfaz clara mediante métodos como Insertar, Eliminar o Buscar. Ejemplos de TDA en C# son las Listas, Pilas y Colas.

P48 48. Algoritmo para eliminar un nodo en Lista

En C#, para eliminar un nodo específico de una lista se realiza un recorrido con objetos de referencia auxiliar y anterior hasta dar con la coincidencia. Una vez localizado el nodo a retirar, se reasigna la propiedad anterior.Siguiente = auxiliar.Siguiente, salteando y desvinculando al nodo de la cadena. Al quedar el objeto sin referencias que lo apunten en la memoria Heap, el recolector de basura (Garbage Collector) de .NET destruye la instancia automáticamente.

P50 50. Diseñe algoritmo para quitar un nodo a una Pila. Use sus propias variables

En C#, para quitar un elemento de la Pila se evalúa primero que la variable de referencia tope no sea null con if (tope != null). Se almacena la información del nodo superior en una variable auxiliar para retornarla y se reasigna tope = tope.Siguiente, desvinculando el nodo de la cima. Al quedar el objeto sin referencias apuntándole dentro de la memoria Heap de .NET, el recolector de basura (Garbage Collector) libera la instancia automáticamente.
